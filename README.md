# 英语口语从小白到大师 · 互动网页书

一个纯静态、可离线使用的英语口语互动练习应用。项目内置 28 个生活与职场场景、84 段对话、1,479 句 MP3 示范音频，并提供逐句播放、跟读识别评分、角色扮演、词汇收藏与复习等功能。

配套文档：[设计文档](DESIGN.md)（架构、数据模型、播放状态机） · [进度记录](PROGRESS.md)（版本交付与验证结论）。

## 功能亮点

- **28 个完整场景，三级难度分层**：全部章节标注 A2（生存必备）/ B1（生活与社交）/ B1+（进阶表达），学习地图提供按级进阶的推荐学习路径；覆盖咖啡店、餐厅、购物、酒店、机场、工作会议、面试、就医、租车、租房、超市、景点等日常与实用场景。
- **84 段情景对话**：每章包含多段对话，可逐句播放、暂停、切换角色和重复收听。
- **五档语速 + 原速听感挑战**：⚡⚡ 1.5x / ⚡ 1.25x / Normal / 🐢 Slow / 🐢🐢 Turtle，加速时保持音调不变，连播时句间停顿随语速自动缩短；🚀 原速挑战以接近母语的语速播放整段对话并隐藏全部文本，练纯听感。
- **角色声音自定义**：设置 → 角色声音，25 个角色可各自选择不同的系统声音（带试听）；对话可在「🎧 HD 录音原声」与「🗣 角色配音（系统语音）」间切换，切换后角色声音直接体现在对话、角色扮演与跟读示范中。
- **播放控制**：支持 ⏮ 上一句 / ⏭ 下一句 / 🔁 单句循环；⏸ 暂停对 MP3 和 TTS 均有效；键盘快捷键：空格 播放/暂停，← → 切句，R 慢速重听。
- **跟读识别评分 + 跟读复习循环**：使用浏览器 Web Speech Recognition 聆听用户朗读，自动从 3 个识别候选中选取最接近的结果评分，并给出漏读、口误与多读提示；不满 85 分的句子自动进入学习地图的「跟读复习」队列，复习达标即移出。
- **角色扮演练习**：选择 Customer、Barista、Waiter 等角色后，应用会播放其他角色台词，轮到用户时可点击「🎤 朗读打分」对自己的台词录音评分。
- **核心语块与替换练习**：按“核心语块 → 情景对话 → 替换练习 → 小测验”的路径组织学习；测验答错时正确答案中的生词可点击收藏。
- **词汇本 + 间隔复习**：点击英文单词查看释义、音标和例句，可收藏生词、搜索筛选；卡片复习支持「认识 / 模糊 / 不会」三档评价，按 10 分钟 → 1 天 → 3 天 → 7 天 → 21 天的间隔安排下次复习。
- **学习统计**：连续打卡天数与每日目标（可在设置中调整），跟读打分、复习卡片、提交测验都计入今日练习。
- **深色模式**：跟随系统或手动切换浅色 / 深色。
- **学习进度**：章节完成状态、测验成绩、上次学习位置、复习计划和收藏词都会保存在浏览器 `localStorage` 中。
- **PWA / 离线缓存**：通过 Service Worker 缓存核心页面和已访问的音频资源；页面文档使用 network-first 策略，更新后刷新即可拿到新版。

## 快速开始

### 方式一：macOS 一键启动

双击项目目录中的：

```bash
start_server.command
```

脚本会启动本地静态服务器，并自动打开浏览器。默认地址是：

```text
http://localhost:8899/index.html
```

如果手机与电脑连接同一 Wi-Fi，终端里显示的局域网地址也可用于手机访问：

```text
http://<电脑局域网 IP>:8899/index.html
```

### 方式二：手动启动

在项目根目录执行：

```bash
python3 -m http.server 8899
```

然后打开：

```text
http://localhost:8899/index.html
```

也可以直接双击 `index.html` 打开基础页面，但 **不推荐**。部分浏览器能力（如 Service Worker、麦克风识别和 PWA 安装）需要 `localhost` 或 HTTPS 安全上下文。

## 部署到静态托管

这是一个纯静态站点，可将整个目录部署到 GitHub Pages、Netlify、Vercel、Cloudflare Pages 等服务。

以 GitHub Pages 为例：

1. 将项目文件推送到 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 将 Source 设置为 `main` 分支的 `/ (root)`。
4. 等待 Pages 构建完成后，访问 GitHub Pages 提供的 HTTPS 地址。

部署后建议使用 HTTPS 访问，以确保离线缓存、语音识别和 PWA 安装体验正常。

## 维护脚本

新增或删除音频文件后，在项目根目录运行：

```bash
node tools/gen-manifest.js   # 重新生成 index.html 中的音频清单
node tools/check.js          # 校验数据完整性
```

## 使用建议

1. 打开 **章节**，选择一个场景。
2. 先学习 **核心语块**，再进入 **情景对话**。
3. 点击句子或播放按钮听示范；觉得慢就用 ⚡ 1.25x / 1.5x，听不清再切 Slow / Turtle。
4. 使用 **跟读打分** 时允许浏览器访问麦克风。
5. 完成替换练习和小测验后，回到 **学习地图** 查看进度、连续打卡和每日目标。
6. 遇到生词时点击单词，加入 **词汇本**，每天用「开始复习」按间隔计划巩固。

## 浏览器与权限

- 推荐 Chrome 或 Edge。
- 跟读识别依赖浏览器的 Web Speech Recognition，不同浏览器和系统支持程度可能不同。
- 部分浏览器会要求先与页面交互后才能播放语音。
- 使用跟读打分时需要允许麦克风权限；某些浏览器的语音识别还需要网络连接。
- 本地学习数据保存在当前浏览器中，清除浏览器数据或更换浏览器后不会自动同步。

## 技术说明

- 前端：HTML、CSS、原生 JavaScript。
- 音频：本地 MP3 文件 + HTML Audio 播放，变速时保持音调（`preservesPitch`）。
- 语音：Web Speech API（Speech Synthesis / Speech Recognition）。
- 存储：`localStorage`，键名为 `english-speaking-book-progress-v1`（含进度、测验成绩、词汇复习计划与每日练习记录）。
- 离线：`sw.js` 页面文档 network-first、静态资源 cache-first；更新代码后刷新页面即可获取新版。

## 重置学习数据

进入 **设置 → 本地学习记录 → 重置进度**，可清除章节进度和测验记录。当前实现会保留已收藏的生词。
